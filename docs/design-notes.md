# 日程记 · 点阵台账

每天先写一份待办清单，完成即盖章，用点阵图看见自己的节奏。

---

## 一、定调说明（Design Direction）

**受众**：需要每天给自己列清单、并想长期看到"我到底做到了多少"的个人用户。
**方向**：`工业实用 Industrial utilitarian × 印刷账簿 print ledger` —— 只走这一个方向，不混搭。

| 决策 | 选择 | 理由 |
|---|---|---|
| 底色 | 暖纸 `#F2ECE1`（非纯白） | 纸的质感让"记录"这个动作有重量感 |
| 墨色 | 暖调近黑 `#1C1A17` | 避免纯黑压纯白的廉价感 |
| 强调色 | 印泥朱红 `#C8401F`，全站唯一 | 只留给两个动作：**记上一笔** 和 **盖章完成** |
| 展示字 | Archivo Black + 思源宋体 700（中文） | 巨大日期数字 + 宋体标题，印刷感 |
| 正文字 | IBM Plex Sans + 思源黑体 | 中性、克制 |
| 数据字 | IBM Plex Mono（`tabular-nums`） | 序号、统计、日期全部等宽对齐 |

**记忆点**：那张点阵图。它同时编码两个维度——

- 点的**直径** = 当天的任务量（0 / 1–2 / 3–4 / 5–7 / 8+，共 5 级）
- 点的**墨色** = 当天的完成度（浅墨 → 深墨，全部完成则变成朱红"盖章"点并带印泥外晕）

一天里所有事都做完，那颗点就会亮成红色——这是整个应用唯一的奖励反馈。

## 二、功能

| 功能 | 说明 |
|---|---|
| 每日清单 | 输入框回车即记录；支持切换到任意历史/未来日期补记或预排 |
| 分模块 | 顶部一排纸标签（全部 / 工作 / 生活 / 写作 / 其他 / ＋），一次只看一个模块；标签上是当天该模块的 完成/总数 |
| 附一条链接 | 输入区第二行可填链接（可选，只认 http(s)），有链接的行尾出现箭头，新标签打开 |
| 盖章完成 | 点方框切换状态，完成瞬间有"盖章"回弹动效 + 朱红删线扫过 |
| 点阵图 | 最近 18 周，双通道编码；点任意一天可跳到那天补记 |
| 生成动效 | 点「生成点阵图」重放对角扫过的生成动画 |
| 统计 | 今日完成数 / 完成度进度条 / 连续完成天数 / 本周完成率 / 累计盖章 |
| 明暗主题 | 跟随系统，可手动切换并记住选择 |
| 持久化 | localStorage（键 `dotledger.v1`），纯本地，不联网 |

## 三、文件结构

```
todo-matrix/
├── index.html            结构、语义地标、内容
├── styles/
│   ├── tokens.css        设计令牌（颜色 / 字阶 / 间距 / 圆角 / 阴影 / 动效）+ 暗色覆盖
```

运行：直接双击 `index.html`，或 `python3 -m http.server` 后访问。无需构建。

## 四、构成与响应式

**PC（>1080px）**：非对称双栏 `1.62fr : 0.9fr` —— 左为台账，右为计分条；点阵图横跨整幅宽度放在下方，给它足够的横向空间。报头巨大日期数字与中文月份刻意重叠（`margin-left: -0.35em`），账本双红线右侧短一截（破格）。

**平板（≤1080px）**：转单栏，工具栏横排。

**手机（≤720px）**：
- 输入区 `position: sticky` 吸顶，拇指可达；按钮撑满宽度
- 行内序号隐藏，把宽度让给任务文本
- 删除按钮常驻（触屏没有 hover）
- 点阵图横向滚动，进入时自动滚到最新一周

## 五、动效规格

| 场景 | 时长 | 缓动 |
|---|---|---|
| 页面入场（4 组，错峰 90ms） | 640ms | `cubic-bezier(0.16,1,0.3,1)` |
| 新增任务行 | 320ms | 同上 |
| 盖章完成 | 620ms | 缩放到 1.34 再回弹，带 -7° 旋转 |
| 点阵图生成扫过 | 520ms | 按 `列×3+行` 计算延迟，形成对角线推进 |

全部动效在 `prefers-reduced-motion: reduce` 下关闭。

## 六、可访问性自检

- 正文对比度：墨 `#1C1A17`/纸 `#F2ECE1` ≈ **13.5:1**；弱化文字 `--ink-muted` ≈ **5.1:1**（实测计算，非目测）
- 朱红按钮配白字 ≈ **5.0:1**；朱红文字用 `--accent-deep` ≈ **6.9:1**
- 所有交互元素 ≥ **44×44px**
- `:focus-visible` 2px 描边 + 2px 偏移，永远可见
- 每个点阵格子是真 `<button>`，带完整 `aria-label`（"10月27日 · 5 项，完成 3 项"）
- 状态变更通过 `role="status" aria-live="polite"` 播报
- 状态不只靠颜色：完成态同时有删线、方框填充、ARIA 三通道
